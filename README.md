# CS 210 Project Three – Corner Grocer

## Project Summary

The Corner Grocer project is a C++ program that analyzes a text file containing grocery items purchased throughout the day. The program allows a user to search for an item’s purchase frequency, display the frequency of every item, and generate a histogram. It also creates a backup file containing the calculated frequencies.

## What I Did Well

I did particularly well organizing the program into separate functions and creating a menu that was easy for the user to navigate. I used a map to store each grocery item and its frequency, which made searching and displaying the data efficient. I also included input validation to prevent invalid menu selections from causing unexpected behavior.

## Areas for Improvement

I could improve the program by making the input validation more detailed and handling file errors with clearer messages. I could also separate the program into additional classes and files to improve organization. These changes would make the program more secure, maintainable, and adaptable for future features.

## Challenges and Resources

The most challenging part was reading the input file, counting repeated items, and producing the histogram correctly. I overcame this challenge by dividing the problem into smaller steps and reviewing examples of file input, maps, loops, and functions. Resources such as course materials, documentation, instructor feedback, and programming communities will remain part of my support network.

## Transferable Skills

This project strengthened my skills in C++, file handling, maps, loops, functions, input validation, and object-oriented programming. These skills will transfer to future coursework, data-structure projects, technical interviews, and software-development work.

## Maintainability, Readability, and Adaptability

I made the program maintainable and readable by using descriptive names, comments, consistent formatting, and separate functions for different responsibilities. The program can be adapted to process other inventory records or include additional reporting features without requiring a complete redesign.
